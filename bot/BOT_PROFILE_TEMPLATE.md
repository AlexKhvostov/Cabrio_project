# Шаблон профиля Telegram-бота CabrioRide

## About
Краткое описание (до 120 символов):
> Клубный бот CabrioRide: поиск авто по фото, визитки, роли, поддержка Telegram Topics.

## Description

- Поиск авто по фото (распознавание номера)
- Фиксация оставленных визиток по фото
- Переход в приложение 
- Уведомления

Как пользоваться:
— В группах:
 • Фото с подписью «?» — поиск авто
 • Фото с подписью «!» — зафиксировать визитку
— В чате с ботом: 
 • Переход в приложение 
 • Фото с подписью — поиск авто
 • Текст с номером авто — поиск авто
 
> Команды работают только в личных сообщениях. Для поиска и визитки используйте фото с "?" или "!" в чате клуба.

## Description picture
Требования к картинке-описанию:
- Логотип CabrioRide (силуэт кабриолета, фирменные цвета)
- Размер: 512x512 px, PNG или JPEG
- В центре — кабриолет с открытым верхом, акцент на динамике и энергии
- Чёрно-бело-красная палитра, современный стиль
- Вокруг или на фоне — иконки/символы функций:
    • Фотоаппарат — поиск авто по фото
    • Визитка — фиксация визитки по фото
    • Щит/пользователь — автоматические роли
    • Чат-баббл с темой — поддержка Telegram Topics
- Без текста и слоганов, только визуальные акценты на функциях

## Botpic
Требования к аватару бота:
- Тот же логотип, что и в Description picture, но без текста
- Формат: 512x512 px, PNG/JPEG

## Commands (BotFather)
```
/start - Начать работу с ботом (только в личных сообщениях)
/help - Справка по возможностям (только в личных сообщениях)
/test - Проверка работы бота (только в личных сообщениях)
/search - Поиск автомобиля по номеру (только в личных сообщениях)
```
> ⚠️ В группах команды не работают! Для поиска по фото используйте подпись "?" или "!" к фото.

## Privacy Policy
> CabrioRide Bot не хранит и не передаёт ваши личные данные третьим лицам. Все фото и номера используются только для идентификации автомобилей в клубе. Данные обрабатываются согласно политике конфиденциальности клуба. Подробнее: [ссылка на политику]
