# 🤖 Telegram Bot CabrioRide

## 🎯 Основные функции

### 📸 Распознавание номеров по фото

#### **Личные сообщения с ботом:**
- Отправьте фото номера автомобиля
- Бот распознает номер и проверит в базе клуба
- Покажет результат и предложит оставить визитку

**Формат ответа:**
```
Распознан номер
🚗 0070MX7
✅ Активный

💼 Оставляешь визитку?
[✅ Да] [❌ Нет]
```

#### **Групповой чат:**
- Отправьте фото с текстом "?"
- Бот автоматически распознает номер и ответит в группу
- Только информационный ответ (без визитки)

**Формат ответа:**
```
Распознан номер
🚗 0070MX7
✅ Активный
```

или

```
Распознан номер
🚗 ABC123
🚫 Нет в клубе
```

### 🔍 Поиск по номеру
- Отправьте номер текстом
- Бот проверит наличие в базе клуба

### 🌐 Интеграция с WebApp
- Кнопка "Зарегистрироваться" → форма регистрации
- Кнопка "Перейти в приложение" → главная страница
- Кнопка "Оставить визитку" → форма визитки

## 🛡️ Безопасность

### Проверка членства
- Все функции доступны только участникам клубного чата
- Автоматическая проверка при каждом взаимодействии

### Роли и права
- **external** — только заглушка с предложением вступить в клуб
- **guest** — базовые функции
- **member+** — полный доступ к функциям

## 📋 Команды

- `/start` — приветствие и проверка членства
- `/help` — справка по командам
- `/test` — проверка работоспособности

## 🔧 Техническая информация

### Архитектура
- **Язык:** PHP 8.1 (PSR-12)
- **Архитектура:** Webhook
- **API:** Telegram Bot API
- **Backend:** REST API для распознавания и поиска

### Структура файлов
```
bot/
├── webhook.php (точка входа)
├── handlers/MessageHandler.php (обработка сообщений)
├── commands/OcrCommand.php (распознавание номеров)
├── services/BotService.php (отправка сообщений)
└── config.php (конфигурация)
```

### Логирование
- Все действия логируются в `bot/webhook.log`
- Подробная отладочная информация
- Аудит для диагностики проблем

## 🚀 Развертывание

1. Настройте `.env` файл с токенами
2. Установите webhook URL в Telegram
3. Проверьте доступность API эндпоинтов
4. Протестируйте все функции

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в `bot/webhook.log`
2. Убедитесь в правильности конфигурации
3. Проверьте доступность backend API
4. Обратитесь к документации в `bot/docs/`
