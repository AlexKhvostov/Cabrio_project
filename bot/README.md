# 🤖 Telegram Bot - CabrioRide

Новый Telegram бот для клуба CabrioRide с чистой архитектурой.

## 📁 Структура проекта

```
bot/
├── config.php              # Конфигурация (токен из .env)
├── webhook.php             # Точка входа для webhook
├── services/
│   └── BotService.php      # Основной сервис для Telegram API
├── handlers/
│   ├── MessageHandler.php  # Главный обработчик сообщений
│   ├── commands/           # Команды бота
│   │   ├── StartCommand.php
│   │   └── HelpCommand.php
│   └── events/             # Обработчики событий чата
│       ├── UserJoinedHandler.php  # Вход в клуб
│       └── UserLeftHandler.php    # Выход из клуба
├── utils/
│   └── Logger.php          # Логирование
└── logs/                   # Логи бота
```

## ⚙️ Настройка

### 1. Переменные окружения

```env

API_URL=http://localhost/app/backend
WEBAPP_URL=http://localhost/app/frontend
```

### 2. Webhook URL
Установите webhook URL в Telegram:
```
https://your-domain.com/app/bot/webhook.php
```

## 🔧 Основные компоненты

### **BotService.php**
- Отправка сообщений
- Проверка членства в чате
- Работа с Telegram API

### **MessageHandler.php**
- Маршрутизация сообщений
- Обработка личных и групповых чатов
- Проверка доступа к клубу
- Обработка событий участников чата

### **UserJoinedHandler.php**
- Обработка входа пользователя в клуб
- Синхронизация данных с БД через API
- Отправка приветственного сообщения
- Установка роли `guest` (ID=2)

### **UserLeftHandler.php**
- Обработка выхода пользователя из клуба
- Обновление роли в БД через API
- Отправка сообщения с сожалением
- Установка роли `external` (ID=1)

### **webhook.php**
- Точка входа для Telegram
- Обработка всех типов обновлений
- Логирование и обработка ошибок

## 🎯 Функциональность

### **Проверка членства**
Бот проверяет, является ли пользователь участником клубного чата:
- ✅ В личных сообщениях - проверяет членство
- ✅ В групповых чатах - проверяет что это клубный чат
- ❌ Не участники получают сообщение с кнопкой вступить

### **Обработка событий чата**
- ✅ **Вход в клуб** - приветствие, синхронизация с БД, роль `guest`
- ✅ **Выход из клуба** - сообщение с сожалением, роль `external`
- ✅ **Интеграция с API** - использование SYSTEM_TOKEN для системных запросов

### **Логирование**
- Подробные логи всех действий
- Логи сохраняются в `bot/logs/`
- Формат: `bot_YYYY-MM-DD.log`

## 🚀 Запуск

1. Убедитесь, что в `.env` настроены все необходимые переменные
2. Установите webhook URL в Telegram
3. Отправьте сообщение боту для тестирования
4. Добавьте бота в клубный чат для тестирования событий

## 📝 Логи

Логи сохраняются в папке `bot/logs/` с датой в имени файла:
```
bot_logs/
├── bot_2024-01-15.log
├── bot_2024-01-16.log
└── ...
```

## 🔄 Разработка

### Добавление новых команд:
1. Создайте обработчик в `handlers/commands/`
2. Добавьте логику в `MessageHandler.php`
3. Протестируйте через webhook

### Добавление новых событий:
1. Создайте обработчик в `handlers/events/`
2. Добавьте логику в `MessageHandler.php`
3. Создайте соответствующий L2 Action в backend
4. Добавьте эндпоинт в SystemController

### Структура обработчика события:
```php
class MyEventHandler {
    public function handle($eventData) {
        // Логика обработки события
        // Синхронизация с БД через API
        // Отправка сообщений
    }
}
```

## 🔗 Интеграция с Backend

### Системные эндпоинты:
- `POST /api/system/user-sync` - синхронизация при входе
- `POST /api/system/user-role` - обновление роли при выходе

### Авторизация:
- Используется `SYSTEM_TOKEN` для системных запросов
- Токен передается в заголовке `Authorization: Bearer <SYSTEM_TOKEN>`

### Роли пользователей:
- `external` (ID=1) - покинул чат
- `guest` (ID=2) - в чате, не зарегистрирован
- `user` (ID=3) - зарегистрирован, не подтверждён
- `member` (ID=4) - подтверждённый участник
- `moderator` (ID=5) - модератор
- `admin` (ID=6) - администратор
