## 🎯 Соответствие стандартам CONVENTIONS.md

### ✅ Пункт 6: Формат ответа
- ✅ Для связанных справочников возвращается раскрытый объект с id, code, name, description
- ✅ Отдельные `*_id` поля не дублируются на верхнем уровне
- ✅ Id всегда доступен внутри объекта (например, role.id)

### ✅ Пункт 14: Передача значений справочников
- ✅ Во всех запросах передается только строковый code
- ✅ Backend ищет id по code в соответствующем справочнике
- ✅ В ответах API возвращается раскрытый объект
