# Интеграционные тесты backend

## Требования к оформлению тестов

1. **Корневой HTML-файл**
   - В каталоге _tests/ должен быть корневой файл (например, `index.php`), в котором структурно перечислены все тесты с кратким описанием и ссылками на их запуск.

2. **Структура каждого теста**
   - В каждом тесте должны быть явно видны:
     - Запрос (метод, URL, тело, заголовки)
     - Ответ (статус, тело)
     - Результат теста (прошёл/не прошёл, краткое пояснение)

3. **Единый стиль**
   - Все тесты оформляются в одном стиле, чтобы было удобно искать ошибки и копировать результаты.
   - Используйте компактное оформление, минимум отступов и пустых строк.
   - Для ошибок и успешных тестов используйте визуальные маркеры (цвет, иконка, короткое сообщение).

4. **Компактность**
   - Минимизируйте отступы и лишние элементы, чтобы уменьшить необходимость прокрутки.
   - Оставляйте только самую важную информацию для быстрой проверки и анализа.

---

## Список тестов
- test_user_registration.php — регистрация пользователя
- test_car_addition.php — добавление автомобиля
- ... (дополняется по мере развития)

## Как запускать
- Каждый тест — отдельный PHP-скрипт или HTML-страница.
- Запуск: php test_user_registration.php или через ссылку из index.html
