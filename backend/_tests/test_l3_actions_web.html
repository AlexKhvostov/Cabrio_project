🧪 Тест L3 Actions

Тестирование L3 Actions с OCR распознаванием номеров

📋 Информация о L3 Actions

  • ___CheckCarInClubAction - Проверка авто в клубе с OCR
  • ___LeaveBusinessCardAction - Оставление визитки с OCR
  • ___AddCarToGarageAction - Добавление в гараж с OCR

Примечание: Все L3 Actions требуют фото автомобиля для OCR распознавания номера.

🔍 ___CheckCarInClubAction

Проверка автомобиля в клубе с OCR распознаванием номера

Используется для настройки глобального контекста

📇 ___LeaveBusinessCardAction

Оставление визитки с OCR распознаванием номера

Используется для настройки глобального контекста

🚗 ___AddCarToGarageAction

Добавление автомобиля в гараж с OCR распознаванием номера

Используется для настройки глобального контекста

❌ Тест без фото

Проверка обработки ошибки при отсутствии фото

Используется для настройки глобального контекста
