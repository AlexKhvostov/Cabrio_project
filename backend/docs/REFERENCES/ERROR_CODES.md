# 📋 Коды ошибок API

> **Назначение:** Полный справочник кодов ошибок API бэкенда CabrioRide  
> **Версия:** 1.0.0  
> **Последнее обновление:** 2024-01-01

---

## 🎯 **Общие принципы**

### **Структура ошибки**
```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "Человекочитаемое описание ошибки",
    "details": {
      "field": "Детали ошибки"
    }
  }
}
```

### **HTTP статусы**
- **400 Bad Request** — ошибки валидации и клиентские ошибки
- **401 Unauthorized** — ошибки авторизации
- **403 Forbidden** — недостаточно прав доступа
- **404 Not Found** — ресурс не найден
- **500 Internal Server Error** — внутренние ошибки сервера

## 🔐 **Ошибки авторизации (401)**

### **NO_TOKEN**
- **Описание:** Токен авторизации не предоставлен
- **Решение:** Добавить заголовок `Authorization: Bearer <token>`
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "NO_TOKEN",
    "message": "Требуется авторизация"
  }
}
```

### **INVALID_TOKEN**
- **Описание:** Токен авторизации недействителен
- **Решение:** Получить новый токен через авторизацию
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "INVALID_TOKEN",
    "message": "Токен недействителен"
  }
}
```

### **NO_TELEGRAM_DATA**
- **Описание:** Данные Telegram не найдены в запросе
- **Решение:** Убедиться, что запрос содержит данные Telegram
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "NO_TELEGRAM_DATA",
    "message": "Данные Telegram не найдены"
  }
}
```

### **TELEGRAM_VALIDATION_ERROR**
- **Описание:** Ошибка валидации данных Telegram
- **Решение:** Проверить корректность данных Telegram
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "TELEGRAM_VALIDATION_ERROR",
    "message": "Ошибка валидации данных Telegram: telegram_id обязателен"
  }
}
```

### **INVALID_HASH**
- **Описание:** Подпись Telegram недействительна
- **Решение:** Проверить корректность подписи Telegram
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "INVALID_HASH",
    "message": "Подпись Telegram недействительна"
  }
}
```

## 🚫 **Ошибки доступа (403)**

### **FORBIDDEN**
- **Описание:** Недостаточно прав для выполнения действия
- **Решение:** Проверить роль пользователя и требуемые права
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "FORBIDDEN",
    "message": "Недостаточно прав для выполнения действия. Требуется роль: member"
  }
}
```

### **ACCESS_DENIED**
- **Описание:** Доступ к ресурсу запрещён
- **Решение:** Проверить права доступа к конкретному ресурсу
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "ACCESS_DENIED",
    "message": "Доступ к ресурсу запрещён"
  }
}
```

## ✅ **Ошибки валидации (400)**

### **VALIDATION_ERROR**
- **Описание:** Ошибка валидации входных данных
- **Решение:** Проверить корректность данных в запросе
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Ошибка валидации",
    "details": {
      "email": "Некорректный формат email",
      "phone": "Телефон обязателен"
    }
  }
}
```

### **MISSING_FIELDS**
- **Описание:** Отсутствуют обязательные поля
- **Решение:** Добавить все обязательные поля в запрос
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "MISSING_FIELDS",
    "message": "Отсутствуют обязательные поля",
    "details": {
      "first_name": "Поле обязательно",
      "telegram_id": "Поле обязательно"
    }
  }
}
```

### **INVALID_FORMAT**
- **Описание:** Некорректный формат данных
- **Решение:** Проверить формат данных согласно документации
- **Пример:**
```json
{
  "success": false,
  "error": {
    "code": "INVALID_FORMAT",
    "message": "Некорректный формат данных",
    "details": {
      "date": "Формат должен быть YYYY-MM-DD"
    }
  }
}
```

```json
  }
}
```

### **DUPLICATE_ENTRY**
- **Описание:** Дублирование записи
- **Решение:** Проверить уникальность данных
- **Пример:**
```json
{
  "success": false,

    "code": "DUPLICATE_ENTRY",

  }

```
