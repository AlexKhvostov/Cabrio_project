# Коды ошибок API CabrioRide

> Централизованный справочник всех возможных ошибок API для backend CabrioRide.
> 
> **Важно:** Все ошибки возвращаются в едином формате через ResponseHelper::error().
> 
> **Формат ошибки:**
> ```json
> {
>   "success": false,
>   "data": null,
>   "error": {
>     "code": "ERROR_CODE",
>     "message": "Человекочитаемое сообщение",
>     "details": { "field": "Детали ошибки" }
>   }
> }
> ```

---

## 🔐 Авторизация и аутентификация (4xx)

| Код | HTTP | Описание | Причины |
|-----|------|----------|---------|
| `NO_TOKEN` | 401 | Требуется авторизация | Отсутствует заголовок Authorization |
| `INVALID_TOKEN` | 401 | Некорректный формат токена | Неверный формат Bearer token |
| `TOKEN_EXPIRED` | 401 | Токен истёк | JWT token с истёкшим сроком действия |
| `INVALID_SIGNATURE` | 401 | Неверная подпись токена | Подделка JWT токена |
| `FORBIDDEN` | 403 | Недостаточно прав | Роль пользователя ниже требуемой |
| `SYSTEM_TOKEN_INVALID` | 401 | Неверный системный токен | Неправильный SYSTEM_TOKEN |

---

## ✅ Валидация данных (4xx)

| Код | HTTP | Описание | Причины |
|-----|------|----------|---------|
| `VALIDATION_ERROR` | 400 | Некорректные данные | Общая ошибка валидации |
| `MISSING_FIELD` | 400 | Отсутствует обязательное поле | Не передано обязательное поле |
| `INVALID_FORMAT` | 400 | Неверный формат данных | Неправильный формат email, телефона и т.д. |
| `INVALID_EMAIL` | 400 | Некорректный email | Неверный формат email адреса |
| `INVALID_PHONE` | 400 | Некорректный номер телефона | Неверный формат номера |
| `INVALID_FILE` | 400 | Некорректный файл | Неподдерживаемый тип файла |
| `FILE_TOO_LARGE` | 400 | Файл слишком большой | Превышен лимит размера файла |
| `INVALID_IMAGE` | 400 | Некорректное изображение | Неподдерживаемый формат изображения |

## 🏢 Бизнес-логика (4xx)

| Код | HTTP | Описание | Причины |
|-----|------|----------|---------|
| `ENTITY_NOT_FOUND` | 404 | Сущность не найдена | Запрашиваемая запись отсутствует в БД |
| `ALREADY_EXISTS` | 409 | Сущность уже существует | Попытка создать дубликат |
| `OPERATION_NOT_ALLOWED` | 403 | Операция запрещена | Бизнес-правила запрещают действие |
| `USER_ALREADY_APPROVED` | 409 | Пользователь уже подтверждён | Повторное подтверждение |
| `USER_ALREADY_BLOCKED` | 409 | Пользователь уже заблокирован | Повторная блокировка |
| `CAR_ALREADY_CLAIMED` | 409 | Автомобиль уже привязан | Попытка привязать к другому владельцу |
| `EVENT_FULL` | 409 | Событие переполнено | Достигнут лимит участников |
| `ALREADY_PARTICIPANT` | 409 | Уже участвует в событии | Повторная запись на событие |
| `NOT_PARTICIPANT` | 409 | Не участвует в событии | Выход из события без участия |

|-----|------|----------|---------|

| Код | HTTP | Описание | Причины |

| Код | HTTP | Описание | Причины |
|-----|------|----------|---------|
| `NOT_FOUND` | 404 | Маршрут не найден | Несуществующий URL |

## 📝 Примеры использования

### В контроллерах:
```php
// Простая ошибка
echo ResponseHelper::error('ENTITY_NOT_FOUND', 'Пользователь не найден');

// Ошибка с деталями
echo ResponseHelper::error('VALIDATION_ERROR', 'Некорректные данные', [
    'email' => 'Некорректный формат email',
    'phone' => 'Номер должен начинаться с +7'
]);

// Ошибка с HTTP кодом
http_response_code(403);
echo ResponseHelper::error('FORBIDDEN', 'Недостаточно прав для выполнения операции');
```

### В логах:
```php
Logger::error('API Error: ' . $errorCode . ' - ' . $message);
```
