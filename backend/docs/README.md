## 🏗️ **Архитектура системы**

### **Уровни абстракции (L0-L4)**
```
L4 (Комплексные) → L3 (Сложные) → L2 (Бизнес) → L1 (Базовые) → L0 (Модели)
```

- **L0 (Модели)** — работа с БД, CRUD операции
- **L1 (Базовые операции)** — простые комбинации L0
- **L2 (Бизнес-операции)** — проверки и правила
- **L3 (Сложные сценарии)** — транзакции и интеграции
- **L4 (Комплексные сценарии)** — полные пользовательские сценарии

### **Основные компоненты**
- **Контроллеры** — HTTP-слой, маршрутизация
- **Actions** — бизнес-логика по уровням
- **Модели** — работа с базой данных
- **Утилиты** — общие функции и хелперы
- **Middleware** — авторизация и валидация

## 🎯 **Actions (бизнес-логика)**

### **L1 Actions (базовые операции)**
- `_CreateUserAction` — создание пользователя
- `_UpdateUserAction` — обновление пользователя
- `_CreateCarAction` — создание автомобиля
- `_UpdateStatusAction` — обновление статуса

### **L2 Actions (бизнес-операции)**
- `__SyncUserDataAction` — синхронизация пользователя
- `__SearchCarAction` — поиск автомобиля
- `__AddCarToUserAction` — добавление авто пользователю
- `__HandleUserJoinedAction` — обработка входа в чат

### **L3 Actions (сложные сценарии)**
- `___CheckCarInClubAction` — проверка авто в клубе (OCR)
- `___LeaveBusinessCardAction` — оставление визитки
- `___AddCarToGarageAction` — добавление в гараж

### **Связи и отношения**
- Пользователи ↔ Автомобили (многие-ко-многим)

- Сущности ↔ Фото (привязка медиа)
