## 🚀 Как запустить

### 1. **Настройка переменных окружения**
Создайте файл `.env` в папке `frontend/`:

```env
# API Configuration
VITE_API_URL=http://localhost/api

# Development settings
VITE_DEV_MODE=true
```

### 2. **Запуск бекенда**
Убедитесь, что бекенд запущен и доступен по адресу `http://localhost/api`

### 3. **Запуск фронтенда**
```bash
cd frontend
npm install
npm run dev
```

## 🔐 Авторизация

### **Telegram WebApp интеграция:**
- Автоматическая передача `initData` в заголовках
- Бекенд проверяет подпись Telegram
- Синхронизация пользователя с базой данных

### **Заголовки запросов:**
```typescript
headers: {
  'Content-Type': 'application/json',
  'X-Telegram-Init-Data': telegramStore.webApp.initData
}
```

## 🛠️ Доступные методы API

### **Пользователи:**
- `GET /api/users` — список пользователей
- `GET /api/users/{id}` — пользователь по ID
- `GET /api/users/profile` — профиль текущего пользователя

### **Автомобили:**
- `GET /api/cars` — список автомобилей
- `GET /api/cars/{id}` — автомобиль по ID

### **Системные:**
- `GET /api/health` — проверка состояния API
