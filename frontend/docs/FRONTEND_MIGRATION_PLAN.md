# 📋 План миграции старого фронтенда CabrioRide

---

## 1️⃣ Текущее состояние проекта

- **Технологии:** Vue 3, TypeScript, Pinia, Vue Router, SCSS, Telegram WebApp SDK.
- **Структура:**
  - Компоненты разбиты по сущностям (cars, members, events, map, services, common).
  - Страницы (views) соответствуют будущей структуре приложения.
  - Pinia store data.ts содержит все mock-данные и функции fetch* для получения данных.
  - Интеграция с Telegram WebApp реализована (init, expand, user, fallback для разработки).
- **UI/UX:**
  - Современный, mobile-first, с bottom navigation, фильтрами, модалками, адаптивностью.
  - Страницы и компоненты хорошо структурированы, легко поддерживаются.
- **Авторизация:**
  - Через Telegram WebApp, с fallback для разработки.
  - Защита маршрутов через meta.requiresAuth и Pinia store telegram.

## 2️⃣ Основные отличия и задачи по интеграции

### 2.1. Данные и API
- Сейчас все данные — mock (Pinia store data.ts).
- Нужно заменить все функции fetch* (fetchCars, fetchMembers, fetchEvents и т.д.) на реальные HTTP-запросы к backend CabrioRide.
- Типы данных (Member, Car, Event и др.) нужно сверить с реальными API-ответами и скорректировать при необходимости.

### 2.2. Авторизация и сессии
- Передавать initData из Telegram WebApp в каждый запрос к API.
- Обрабатывать ошибки авторизации (401/403) — редиректить на /login или /access-denied.
- Сессия должна быть ограничена по времени (30 минут), после чего — повторная авторизация.

### 2.3. UI/UX и дизайн
- Провести ревью компонентов и страниц на соответствие актуальным дизайн-гайдам CabrioRide.
- При необходимости — доработать стили, отступы, цвета, иконки (использовать DESIGN/).
- Проверить адаптивность и корректную работу на мобильных устройствах.

### 2.4. Страницы и роутинг
- Сопоставить существующие страницы с новой структурой (1–10).
- Добавить/переименовать маршруты, если потребуется.
- Проверить, что все защищённые маршруты корректно работают с авторизацией.

### 2.5. Удаление mock-данных
- После успешной интеграции с API — удалить все mock-данные и временные заглушки из data.ts.
