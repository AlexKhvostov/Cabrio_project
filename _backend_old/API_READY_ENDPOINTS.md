# ✅ Реализованные эндпоинты CabrioRide

> Вся архитектура авторизации, сессий и ролей описана в [docs/AUTH_ARCHITECTURE.md](../docs/AUTH_ARCHITECTURE.md).

---

## 🔐 Авторизация
> Эндпоинты для входа через Telegram, проверки и завершения сессии пользователя.

| Метод | Endpoint | Файл | Описание |
|-------|----------|------|----------|
| POST | /api/auth/telegram | auth/telegram.php | Авторизация через Telegram WebApp (создание/обновление пользователя и сессии) |
| POST | /api/auth/check | auth/check.php | Проверка текущей авторизации пользователя (валидность сессии, информация о пользователе) |
| POST | /api/auth/logout | auth/logout.php | Завершение сессии пользователя (выход из системы) |

---

## 👤 Пользователи
> Операции с профилем пользователя: создание, получение, обновление.

| Метод | Endpoint | Файл | Описание |
|-------|----------|------|----------|
| POST | /api/users/profile | users/profile.php | Получение профиля пользователя (своего или по user_id) |
| POST | /api/users/add | users/add.php | Добавление нового пользователя (обычно при первой авторизации через Telegram) |
| POST | /api/users/update | users/update.php | Обновление профиля пользователя (имя, фамилия, фото и др.) |
| POST | /api/users/set_role | users/set_role.php | Смена роли пользователя (только для moderator+; логирование в moderation_logs) |

## 🚗 Автомобили
> Добавление и проверка автомобилей участников клуба.

| Метод | Endpoint | Файл | Описание |
|-------|----------|------|----------|
| POST | /api/cars/add | cars/add.php | Добавление автомобиля (рег. номер, фото, модель, год, цвет и др.) |
| POST | /api/cars/check | cars/check.php | Проверка автомобиля по номеру (поиск в базе, статус, id) |
| POST | /api/cars/update | cars/update.php | Обновление автомобиля (статус, цвет, модель, владелец — только для модератора/админа) |

## 📸 OCR (распознавание номеров)
> Работа с фото автомобилей: распознавание номера и проверка его в базе клуба.

| Метод | Endpoint | Файл | Описание |
|-------|----------|------|----------|
| POST | /api/ocr/recognize | ocr/recognize.php | Распознавание номера автомобиля по фото (интеграция с внешним сервисом OCR, возвращает номер, уверенность, регион) |
| POST | /api/ocr/check | ocr/check.php | Проверка распознанного номера в базе клуба (есть ли такой авто, статус, можно ли оставить визитку) |
| POST | /api/ocr/process | ocr/process.php | Объединённый эндпоинт: распознаёт номер, возвращает номер (в верхнем регистре), уверенность, найден/не найден, статус авто. Полностью поддерживается современной тестовой страницей (backend/_test/ocr/process.html) |

## 💼 Визитки
> Оставление визитки на автомобиль участника клуба (например, для приглашения в клуб).

| Метод | Endpoint | Файл | Описание |
|-------|----------|------|----------|
| POST | /api/business-cards/add | business-cards/add.php | Создание визитки (оставить визитку на авто, прикрепить фото, указать место и заметки) |
| POST | /api/business-cards/add_to_car | business-cards/add_to_car.php | Добавление визитки к существующей машине (по car_id или reg_number) |
| POST | /api/business-cards/add_full | business-cards/add_full.php | Оркестратор: добавление машины и визитки (если машины нет) |
| POST | /api/business-cards/auto_add | business-cards/auto_add.php | Оркестратор: автоматическое добавление визитки по номеру (создаёт авто и визитку, если машины нет, или только визитку, если машина есть) |
| POST | /api/photos/add | photos/add.php | Добавление фото к любой сущности (авто, пользователь, событие и др.), поддержка base64 и url |

---

> Все эндпоинты возвращают ответы в едином формате (JSON), подробности — см. документацию по API.
> Этот список будет пополняться по мере появления новых реализованных эндпоинтов.
