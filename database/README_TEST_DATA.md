## 🚀 Как использовать

### 1. Заполнение базы данных
```bash
# Подключитесь к MySQL и выполните:
mysql -u your_user -p cabrioride < database/scripts/003_fill_test_data.sql
```

### 2. Тестирование API
```bash
# Тест поиска автомобиля Lex
curl -X POST http://localhost/api/plate-search \
  -H "Content-Type: application/json" \
  -d '{"plate": "9588MI1"}'

# Ожидаемый результат:
# {"success":true,"found":true,"status":"active"}
```

### 3. Тестирование бота
- Отправьте боту фото автомобиля с номером `9588MI1`
- Бот должен найти автомобиль Lex в базе данных
- Отправите боту номер `1234AB7` - должен найти Mercedes Ивана
