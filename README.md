# CabrioRide 🚗

> **Клубное приложение для владельцев кабриолетов** — объединяем единомышленников, вдохновляем на новые поездки и создаём безопасное пространство для общения.

## 📋 О проекте

CabrioRide — это не просто IT-платформа, а живое сообщество единомышленников, объединённых любовью к кабриолетам, свободе и открытым дорогам. Мы создаём пространство, где каждый участник — не просто ник в чате, а реальный человек с историей, машиной, опытом и вкладом в клуб.

### 🎯 Миссия
**Объединять, вдохновлять и поддерживать владельцев кабриолетов, делая клуб максимально открытым, удобным и безопасным для своих.**

### ✨ Ключевые возможности
- **Telegram WebApp** — всё в одном месте, привычный интерфейс
- **Привязка профиля к реальному авто** — прозрачность и доверие
- **Система ролей** — только реальные владельцы, никакого спама
- **Организация событий** — легко планировать, удобно участвовать
- **База гид-объектов** — только проверенные рекомендации
- **Визитки и поиск** — расширяем клуб, не раскрывая личные данные

## 🛠 Технологический стек

### Backend
- **PHP 8.1** (PSR-12) — основной серверный язык
- **MySQL 8.0** — база данных
- **Apache 2.4** — веб-сервер
- **Telegram Bot API** — интеграция с Telegram

### Frontend
- **Vue.js 3** — прогрессивный JavaScript фреймворк
- **TypeScript** — строгая типизация
- **Pinia** — управление состоянием
- **Vue Router** — маршрутизация
- **Telegram WebApp SDK** — интеграция с Telegram

### Инфраструктура
- **XAMPP** — локальная среда разработки
- **Node.js 18+** — сборка фронтенда
- **PowerShell** — командная строка Windows

## 🚀 Быстрый старт

### Предварительные требования
- Windows 10/11
- XAMPP с PHP 8.1
- Node.js 18+
- MySQL 8.0
- PowerShell

### 1. Клонирование проекта
```powershell
Set-Location -Path C:\xampp\htdocs
git clone <repository-url> app
Set-Location -Path app
```

### 2. Настройка окружения
```powershell
# Создание .env файла
Copy-Item .env_example .env
# Настройка переменных окружения в .env
```

### 3. Установка зависимостей Frontend
```powershell
Set-Location -Path frontend
npm install
```

### 4. Настройка базы данных
```powershell
Set-Location -Path database/scripts
# Запуск SQL-скриптов для создания таблиц и тестовых данных
```

### 5. Запуск разработки
```powershell
# Frontend (в отдельном терминале)
Set-Location -Path frontend
npm run dev

# Backend (через XAMPP)
# Запустить Apache и MySQL в XAMPP Control Panel
```

## 🏗 Архитектура

### Backend (PHP)
- **MVC архитектура** — разделение логики и представления
- **REST API** — стандартные HTTP методы
- **RPC Actions** — сложные бизнес-операции
- **Middleware** — проверка авторизации и валидация
- **Singleton Database** — единое подключение к БД

### Frontend (Vue.js)
- **Composition API** — современный подход к компонентам
- **Pinia Store** — централизованное управление состоянием
- **Vue Router** — клиентская маршрутизация
- **TypeScript** — строгая типизация
- **Telegram WebApp SDK** — интеграция с Telegram

### База данных (MySQL)
- **Нормализованная структура** — минимизация дублирования
- **Внешние ключи** — целостность данных
- **Индексы** — оптимизация запросов
- **Транзакции** — атомарность операций

## 🔐 Безопасность

- **Telegram авторизация** — вход только через Telegram
- **Роли и права доступа** — система ролей (external, guest, new, registered, member, moderator, admin)
- **Валидация данных** — проверка всех входных данных
- **SQL Injection защита** — использование подготовленных запросов
- **XSS защита** — экранирование вывода

## 📊 Мониторинг и логирование
