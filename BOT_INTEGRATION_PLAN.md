# План интеграции Telegram бота с Backend API

## 🎯 Цель
Интегрировать Telegram бота с backend API для выполнения OCR распознавания и поиска автомобилей в базе клуба.

## 📋 Анализ требований

### ✅ Что уже описано в документации:
1. **OCR распознавание** - `POST /api/ocr`
   - Принимает фото автомобиля
   - Возвращает распознанный номер и статус в клубе
   - Формат: multipart/form-data

2. **Поиск по номеру** - `POST /api/plate-search`
   - Принимает текстовый номер
   - Возвращает факт наличия в базе
   - Формат: JSON

### 🔍 Что нужно реализовать в backend:

## 1. API эндпоинты для бота

### 1.1 OCR распознавание
```
POST /api/ocr
Content-Type: multipart/form-data
Body: upload (file)

Ответ:
{
  "success": true,
  "plate": "A123BC77",
  "region": "BY", 
  "confidence": 0.95,
  "club_status": {
    "found": true,
    "status": "active"
  }
}
```

### 1.2 Поиск по номеру
```
POST /api/plate-search
Content-Type: application/json
Body: { "query": "A123BC77" }

Ответ:
{
  "success": true,
  "found": true,
  "status": "active"
}
```
