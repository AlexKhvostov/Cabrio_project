# Среды CabrioRide: локальная, тест и бой

Актуально на 8 сентября 2026.

У приложения **три места**, где оно может жить. Это не три разных кода, а **три копии одного проекта** с разными адресами, ботами и файлами `.env`.

> Секреты (пароли, токены) в этот файл не пишем. Они только в `.env` на каждой среде и в локальной папке `.secrets/` (в git не попадают).

## Зачем так

- **Локально** — правим код на компьютере, клуб это не видит.
- **Тест (dev)** — проверяем на настоящем хостинге и в Telegram, не трогая живой клуб.
- **Бой (prod)** — то, чем пользуются участники каждый день.

Правило: сначала локально → потом тест → на бой **только по прямой команде** владельца («заливай на прод» / «на бой»). Фраза «заливай» без уточнения = **сначала спросить, куда**.

## Сводка

| | Локально | Тест (dev) | Бой (prod) |
|---|---|---|---|
| Для кого | разработчик | владелец и проверка | участники клуба |
| Адрес приложения | `http://localhost/Cabrio_app/frontend/` | `https://dev.cabrioride.by/app/frontend/` | `https://cabrioride.by/app/frontend/` |
| Папка с кодом | `C:\xampp\htdocs\Cabrio_app` | `www/dev.cabrioride.by/app` | `www/cabrioride.by/app` |
| Telegram-бот | свой тестовый / не обязателен | `@CabrioControl_bot` (не клубный) | `@CabrioRideBot` |
| Webhook бота | обычно не нужен | `https://dev.cabrioride.by/app/bot/webhook.php` | `https://cabrioride.by/app/bot/webhook.php` |
| `.env` | свой, на компьютере | свой, на сервере в папке `app` | свой, на сервере в папке `app` |
| `APP_URL` в `.env` | локальный URL | `https://dev.cabrioride.by/app/frontend/` | `https://cabrioride.by/app/frontend/` |
| База данных | своя локальная **или** общая (см. ниже) | пока **та же, что на бою** | боевая MySQL на хостинге |

Почему везде путь `/app/...`: в коде зашиты ссылки вида `/app/frontend/...`. На тесте **нельзя** класть файлы в корень `dev.cabrioride.by` и ждать, что откроется как `/`. Нужна вложенная папка `app`, как на бою.

## 1. Локально (компьютер)

- Windows + XAMPP, рабочая папка `C:\xampp\htdocs\Cabrio_app`.
- GitHub-клон: правки сами на сайт **не уезжают**.
- Настройка машины и пример `.env`: [ENVIRONMENT.md](ENVIRONMENT.md).
- Участники клуба эту копию не видят.

**Состояние на 8 сентября 2026:**

- Код залит в `www/dev.cabrioride.by/app` (свой `.env`, не копия боевого). На сервере лежит снимок на момент заливки; свежие правки с компьютера туда сами не едут.
- DNS `dev.cabrioride.by` отвечает (`5.44.44.227`), HTTPS и API health работают.
- Тестовый бот `@CabrioControl_bot`: webhook = `https://dev.cabrioride.by/app/bot/webhook.php`.
- Фото для просмотра берутся с боя (`UPLOADS_BASE_URL` = `https://cabrioride.by/app/uploads`).
- Токен бота только в `.secrets/` (не в git).

Тестовый бот **нельзя** направлять на прод, клубный `@CabrioRideBot` **нельзя** направлять на dev. Токены в чат и в git не дублируем.

## 3. Бой — `cabrioride.by`

| | |
|---|---|
| Сайт | https://cabrioride.by/app/frontend/ |
| Папка | `www/cabrioride.by/app` |
| Бот | `@CabrioRideBot` → `https://cabrioride.by/app/bot/webhook.php` |
| Как выкладывать | [DEPLOYMENT.md](DEPLOYMENT.md) — FTP, только по команде |

**Никогда не затирать на бою:** `.env`, загрузки (`uploads/`), логи. Соседние сайты в аккаунте (`club` и т.д.) не трогаем.

## База данных

Пока **тест и бой смотрят в одну боевую базу**. Это сознательно, чтобы не плодить вторую копию всех участников.

Следствия:

- На тесте **нельзя** массово править, удалять или «чистить» данные клуба.
- Для проверки лучше трогать свои тестовые записи (свой профиль, своё авто).
- Когда понадобится отдельная тестовая база — это отдельное решение владельца, не делать молча.

Локально база может быть своей (XAMPP) — это не связано с боем, пока в локальный `.env` не прописали боевые доступы.

## Что должно отличаться в `.env` теста и боя

Одинаковый код, **разные** значения:

- `BOT_TOKEN` — тестовый бот vs клубный
- `APP_URL` / `BASE_URL` / `BACKEND_API_URL` — `dev.cabrioride.by` vs `cabrioride.by`
- webhook в Telegram — на свой домен (см. таблицу выше)
- `APP_ENV` на бою = `production`; на тесте можно `production` (как «настоящий сервер») или отдельно согласовать

Пример полей без секретов: [.env_example](../.env_example).

## Выкладка: куда что копировать

Один FTP-аккаунт видит обе папки. Перепутать их нельзя.

| Команда владельца | Куда копировать |
|---|---|
| «на тест» / «на dev» / «на черновик» | `www/dev.cabrioride.by/app` |
| «на бой» / «на прод» / «заливай участникам» | `www/cabrioride.by/app` |
| просто «заливай» | **спросить**, не копировать |

Как технически заливать: [DEPLOYMENT.md](DEPLOYMENT.md).

## Короткий чеклист перед боем

1. Правки проверены локально.
2. Та же сборка лежит на тесте и открывается из **тестового** бота.
3. Владелец явно сказал выкладывать на бой.
4. На бою не перезаписан `.env` и не сменён webhook клубного бота на dev.
