# 🔍 OCR Интеграция - Распознавание номеров автомобилей

## 📋 Обзор

Система использует API **platerecognizer.com** для распознавания номеров автомобилей из фотографий.

```env
OCR_TOKEN=adc5c5a5ea976e1b3bcb27d20f220f6c3c4506dc
```

## 📸 Требования к изображениям

- **Размер файла**: не более 3MB
- **Формат**: JPEG или PNG
- **Рекомендуемое разрешение**: 1024×768
- **Ориентация**: портретная (предпочтительно)
- **Автомобиль**: минимум 15% площади изображения
- **Номер**: должен быть читаемым человеком

## 🔍 API Endpoints

### platerecognizer.com
- **URL**: `https://api.platerecognizer.com/v1/plate-reader/`
- **Метод**: POST
- **Авторизация**: Token в заголовке
- **Регион**: Россия (`regions=ru`)

## 🛠️ Архитектура

### IntegrationHelper
- `recognizePlateNumber()` - основной метод
- `prepareImageForOCR()` - подготовка изображения
- `callOCRAPI()` - вызов внешнего API
- `validatePlateNumber()` - валидация результата

### RecognizeCarNumberFromPhotoAction (Utils)
- OCR утилита для распознавания номеров
- Простой интерфейс: `handle($photoFile)`
- Возвращает строку с номером или исключение
- Логирование результатов

## 🔧 Настройка для разработки

## 🚨 Обработка ошибок

### Типичные ошибки:
- `OCR_TOKEN не найден в переменных окружения`
- `Размер файла превышает 3MB`
- `Неподдерживаемый тип файла`
- `Не удалось прочитать файл изображения`
- `Номер автомобиля не найден на изображении`
- `OCR API ошибка: [детали]`

## 📈 Мониторинг

Логи сохраняются в:
- `backend/logs/app.log` - успешные операции
- `backend/logs/error.log` - ошибки

## 🔄 Интеграция в MVP

OCR используется в следующих MVP функциях:
1. **Проверка авто** - распознавание номера для поиска в БД
2. **Оставление визитки** - распознавание номера для создания записи
3. **Добавление в гараж** - распознавание номера для привязки к пользователю
