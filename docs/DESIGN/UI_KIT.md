# UI Kit CabrioRide

**Канон зафиксирован 8 сентября 2026.** Живые экраны приложения копируют этот kit. Новый экран или модалка сначала появляется здесь (с номером пункта), затем переносится в код раздела теми же классами и токенами.

Живая страница со всеми компонентами и номерами (удобно править по пунктам):

**https://dev.cabrioride.by/app/frontend/pages/ui_kit.php**

Локально: `frontend/pages/ui_kit.php`. Номера пунктов не меняем без согласования.

**UI Kit 2** — проба темы «сумерки» (не канон): `frontend/pages/ui_kit2.php`. Живые экраны её не копируют, пока не решим перенести.

Компактный тёмный стиль Mini App: графитовый фон `#070b12`, аквамарин `#46e0d6`, стекло на карточках. Один набор токенов на списки, профиль и модалки — файл `frontend/assets/css/styles.css`.

Каталог организован как рабочая библиотека:

- слева — компактное оглавление по категориям;
- контентная колонка имеет ширину среднего телефона — 390px;
- сложные карточки, меню и модалки занимают всю ширину;
- каждый пункт содержит живой визуальный пример, а не только текстовое описание;
- на мобильной ширине каталог автоматически становится одноколоночным.

## Принципы

- Mobile-first, Telegram Mini App, без визуального шума
- Пустое поле **не прячем**: серая подпись «не указано» напоминает заполнить
- Карточка авто и карточка человека — два полноценных объекта. Внутри только **ссылка** на другое (строка с ›), не плитка из списка
- Редактирование везде одинаково: справа в шапке **Изменить** → **Отмена** + **Сохранить**. Фото грузится только в режиме правки
- Карточка другого участника: **Написать** справа в строке с именем (диалог Telegram по @username). Без username кнопки нет; свою карточку не пишем сами себе
- Смена роли в списке (п. 79): только для модератора/администратора; свайп открывает одно соседнее действие, а применение требует отдельного нажатия и подтверждения

## Шрифт

Системный стек (как в Telegram). Размеры:

- подпись поля: 10px, uppercase
- вторичный текст: 11px
- основной текст / кнопки / поля: 12px
- заголовок карточки: 13px
- имя: 14px
- приветствие: 16px
- пункт нижнего меню: 10px

## Кнопки

- **ghost** — Изменить, Отмена: рамка, прозрачный фон, 28px высота, 12px
- **primary** — Сохранить, главное действие: градиент акцента
- **icon** — закрыть модалку: 32×32
- Не использовать оранжевый как основную кнопку правки

## Нижнее меню

Значки — единый набор мягких 3D-иллюстраций на графитовом фоне (не линейный контур и не эмодзи). Активный пункт — бирюзовая черта сверху и тонкое кольцо вокруг плитки. В «Профиле» при наличии фото — своё фото вместо нейтральной иллюстрации.

## Поля

Поля идут одной последовательной колонкой внутри общей рамки. Эталон — пункты 23, 55 и 56: короткая строка **подпись слева, значение справа**. Длинный текст (описание, VIN, «о себе») — класс `full`: подпись сверху, текст снизу.

Правка: тот же ряд, внутри инпут без второй рамки (пункт 25).

## Карточки

**Список:** компактная плитка (человек — строка, авто / событие / отзыв — фото 16:9). У человека справа: одна машина — широкая мини-карточка 84×42; две — две карточки 64×42 рядом; нахлёст применяется только для 3+, когда отдельные карточки уже не помещаются. На каждой видимой машине подписана марка; для 3+ марки дополнительно перечислены мелкой строкой под данными участника, при 4+ показывается +N.

**Плитка события (п. 67):** справа на фото — сегодня / завтра / через N дней. Внизу слева «едут» и «думают», справа за чертой свободные места. Свой ответ — рамка и ✓ на блоке людей (с гостем ✓+1).

**Плитка отзыва (п. 68):** одна строка — средняя и звёзды слева, справа капсула с числом отзывов. Рамка и цифра: до 2,5 ★ красно-оранжевая, до 4 ★ жёлтая, 4–5 ★ зелёная.

**Модалка события (п. 58):** «Кто ответил» — заголовок блока, рубрики Едут / Думают / Не едут ярче имён, счётчик справа, имена столбиком тише, гость +1.

**Правка события (п. 72):** тот же каркас, что п. 58. Название, описание, дата, место, тип, лимит и «по приглашению» чуть светлее. Статус и автор без правки. Регистрация как в просмотре.

**Создание события (п. 64):** те же поля встречи, без автора, статуса и блока регистрации. Кнопки внизу.

**Модалка места (п. 59):** под фото название, описание, ярлыки отдельной плашкой; автор тонкой строкой. Дальше три средние, «Поставить отзыв», список отзывов.

**Правка места (п. 71):** тот же каркас, поля названия / описания / ярлыков чуть светлее.

**Создание места (п. 65):** название → описание → ярлыки.

**Большая карточка (модалка и Профиль):**

1. Шапка: название раздела слева («Участник», «Автомобиль», «Событие»), действия справа
2. Фото
3. Ссылка на связанный объект (хозяин или его авто)
4. Последовательный список смысловых групп, включая пустые поля

Профиль — та же карточка человека, без крестика, с тем же «Изменить».

## Шапка и подсказка раздела

- **П. 69.** Стартовый экран Mini App: обложка ~2:1, приветствие, шесть плиток **по три в ряд**, блок «про нас», подсказки, внизу **справка** «Как устроен клуб» (плитки «Роли и доступы» → п. 73, «Разделы» → п. 75).
- **П. 70.** Не в клубном чате (роль external): обложка, ссылка в группу и кнопка повторной проверки после вступления.
- **П. 46.** В полоске Telegram всегда **CabrioRide**, под ним название текущего раздела и кнопка **i**.
- У цифр на плитке события отдельной **i** нет: смысл колонок написан в подсказке шапки раздела «События».
