# Компонент: BottomMenu (Нижнее меню)

Фиксированное меню внизу экрана. На всех экранах приложения, кроме лендинга вне Telegram.

Старт приложения — экран статистики (`frontend/index.php`). В меню его **нет**: пользователь уходит в разделы сам.

## Кнопки (слева направо)

1. Участники — список людей
2. Авто — список машин
3. Карта — «видеть своих»
4. События — поездки и встречи (`pages/events.php`)
5. Отзывы — карточки клуба: мойки, масла, сервисы (`pages/services.php`)
6. Профиль — свой профиль

Значки **картинки** в маленькой плитке (не линейный контур, не эмодзи): так разделы читаются сразу. Активный пункт — цвет клуба, короткая черта сверху и кольцо вокруг плитки.

События и гид в меню уже есть; содержимое разделов подключаем по ТЗ отдельно.

## Состояния
- Активная вкладка (подсветка сверху)
- Неактивная вкладка
