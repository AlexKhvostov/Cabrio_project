# Экран «Отзывы»

Раздел нижнего меню **Отзывы**. Страница: `frontend/pages/services.php`. В коде список и API — `guide_objects`.

## Обязательные элементы
- [Header](../COMPONENTS/Header.md) — название «Отзывы» и кнопка **i**
- [BottomMenu](../COMPONENTS/BottomMenu.md)

## Назначение
Карточки клуба (мойки, масла, средства, кафе, сервисы) и оценки участников. Доступ — по ролям в `sectionGroups.php` (обычно member+).

## Основные элементы
- Поиск, в том числе по ярлыку `#мойка`
- Сетка плиток с фото и оценкой
- **+** — новая карточка (фото, название, описание, ярлыки)
- Большая карточка: оценки, список отзывов, форма отзыва поверх
