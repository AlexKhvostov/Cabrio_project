# Экран карты

![Скриншот карты](../../../ref/map.png)

## Обязательные элементы интерфейса
- [Header (хедер)](../COMPONENTS/Header.md) — всегда вверху
- [BottomMenu (нижнее меню)](../COMPONENTS/BottomMenu.md) — всегда внизу

## Назначение
Показать, где сейчас свои: живые точки участников, которые делятся геолокацией. Карта доступна для просмотра сразу; чтобы тебя видели другие, нужно включить кнопку ⏻.

## Основные элементы
- Яндекс.Карта (центр по умолчанию — Минск)
- Список «Сейчас на карте»
- Метки с аватарками; по нажатию — имя
- Кнопка ⏻ «показывать меня»
- Кнопка «держать меня в центре» (пока геолокация включена)
- Подсказка, пока пользователь себя не показывает
