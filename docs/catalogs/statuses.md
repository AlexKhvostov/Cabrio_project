# Справочник статусов (ref_statuses) - ТОЛЬКО для автомобилей

| code           | name         | description                | color      | entity_type |
|----------------|--------------|----------------------------|------------|-------------|
| active         | Активен      | Активный автомобиль участника | #4CAF50 | car        |
| pending        | На модерации | Ожидает проверки модератором | #FFC107 | car        |
| verified       | Проверен     | Проверен модератором       | #2196F3 | car        |
| blocked        | Заблокирован | Заблокирован (подозрительный номер, нарушение правил) | #F44336 | car |
| archived       | В архиве     | В архиве (продан, не используется) | #BDBDBD | car |
| deleted        | Удалён       | Удалён из системы          | #9E9E9E | car        |
| noticed        | Замечен      | Автомобиль замечен ботом по фото, владелец не найден | #FFD700 | car |
| business_card  | Визитка      | Авто добавлено по визитке, владелец не подтверждён | #17a2b8 | car |

---

- Статусы используются для управления жизненным циклом автомобилей.
- Цвет помогает визуально различать статусы в интерфейсе.
- entity_type указывает, для какой сущности применяется статус.
- Справочник синхронизируется с бизнес-логикой и схемой БД.
