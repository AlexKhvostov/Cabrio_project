# 📋 Техническое задание на разработку Backend CabrioRide

> Вся логика авторизации, сессий, ролей и идентификации описана в [docs/AUTH_ARCHITECTURE.md](../docs/AUTH_ARCHITECTURE.md). Здесь приведены только backend-специфика и архитектурные требования.

## 🎯 Цель проекта
Разработка backend-части клубного приложения CabrioRide для владельцев кабриолетов.

## 🛠 Технический стек
- PHP 8.1 (PSR-12)
- MySQL 8.0
- Apache + mod_rewrite
- Хостинг: hostland.ru

## 📦 Основные компоненты
1. **API для WebApp**
   - REST API для взаимодействия с фронтендом
   - JSON формат данных
   - Авторизация через Telegram WebApp
   - Валидация и санитизация входных данных

2. **Telegram Bot API**
   - Webhook архитектура
   - Интеграция с platerecognizer.com для распознавания номеров
   - Проверка членства в чате
   - Отправка уведомлений

3. **База данных**
   - MySQL 8.0
   - Полная схема в DATABASE_SCHEMA.md
   - Миграции в /database/scripts/
   - Тестовые данные для разработки

## 🔒 Требования безопасности
1. Все токены и ключи только в .env
2. Валидация всех входных данных
3. Защита от SQL-инъекций через PDO
4. Проверка прав доступа для каждого endpoint
5. Логирование критических операций
6. CORS настройки для безопасности

## 📁 Структура проекта
```
backend/
├── api/           # API endpoints
│   ├── auth/      # Авторизация
│   ├── cars/      # Управление авто
│   ├── events/    # События
│   ├── users/     # Пользователи
│   ├── ocr/       # Распознавание номеров
│   └── guide/     # Гид-объекты
├── config/        # Конфигурация
├── models/        # Модели данных
└── utils/         # Утилиты
```

## 📝 Требования к коду
1. Строгое следование PSR-12
2. Комментарии на русском языке
3. Документация для каждого endpoint
4. Единый формат ответов API
5. Централизованная обработка ошибок
6. Информативное логирование

## 🔄 Процесс разработки
1. Каждый endpoint тестируется отдельно
2. Обязательное логирование ошибок
3. Проверка на тестовых данных
4. Code review перед production

## ⚡ Критически важные моменты
1. Работа с ролями (не статусами!) пользователей
2. Проверка членства в чате
3. Корректная работа с фото (загрузка, обработка)
4. Правильная обработка ошибок
5. Безопасное хранение токенов

## 🎯 Приоритеты разработки
1. API авторизации через Telegram
2. Распознавание номеров (OCR)
3. Базовые CRUD операции
4. Уведомления и интеграции
5. Дополнительный функционал

## 📊 Метрики качества
1. Время ответа API < 1 сек
2. Успешное распознавание номеров > 90%
3. Корректная обработка ошибок 100%
4. Отсутствие утечек памяти
5. Логирование всех критических операций
