# 📸 Алгоритм обработки фото с подписью "++" в групповом чате CabrioRide

---

## 1️⃣ Получение/создание пользователя по Telegram ID
- **Первым делом** делаем запрос к `/api/users/profile.php`:
  - `auth`: `{ user_id: 1, role: 'admin' }`
  - `data`: `{ telegram_id: ... }`
- Если пользователь найден — получаем его `user_id` и `role`.
- Если не найден — создаём через `/api/users/add.php` (с теми же auth, передаём все доступные данные из Telegram).
- После этого у нас есть актуальные `user_id` и `role` для всех дальнейших действий.

---

## 2️⃣ Распознавание номера по фото
- Отправляем фото на `/api/ocr/recognize.php`.
- В запросе используем `auth`: `{ user_id, role }` (только что полученные).
- Если не распознался — сразу ошибка и рекомендации (сообщение пользователю, завершение обработки).
- Если распознался — **номер обязательно приводим к ВЕРХНЕМУ РЕГИСТРУ только для отображения на экране!**

---

## 3️⃣ Проверка авто по распознанному номеру
- `/api/cars/check.php` с `auth`: `{ user_id, role }` и `data`: `{ reg_number: ... }` (номер как есть, без преобразования регистра).
- Анализируем результат:
  - **Авто найдено:**
    - Если `owner_user_id` = текущий user_id:
      - Обновляем статус авто на "активный" (если требуется).
      - Добавляем фото к авто через `/api/photos/add.php`.
      - **Примечание:** Для добавления фото используем отдельный эндпоинт.
    - Если `owner_user_id` = NULL:
      - Присваиваем авто пользователю (`/api/cars/claim.php`).
      - Обновляем статус авто на "активный".
      - Добавляем фото к авто через `/api/photos/add.php`.
    - Если `owner_user_id` ≠ user_id и не NULL:
      - Сообщаем, что у авто другой владелец. Не раскрываем, кто именно.
      - Не добавляем фото, не меняем статус.
  - **Авто не найдено:**
    - Добавляем авто через `/api/cars/add.php` (текущий пользователь — владелец).
    - **Фото прикладывается прямо в этом эндпоинте, отдельный вызов не требуется!**

---

## 4️⃣ Формирование сообщения пользователю
- Всегда указываем распознанный номер (в верхнем регистре, только для экрана).
- Не раскрываем чужие данные (например, кто владелец авто).
- Сообщения лаконичные и информативные:
  - Если не распознан номер:
    ```
    ❌ Не удалось распознать номер на фото.
    💡 Советы: сделайте чёткое фото, избегайте бликов и теней.
    ```
  - Если у авто другой владелец:
    ```
    🚗 Номер: ХХХХХХ
    ⚠️ У этого авто уже есть владелец. Если это ошибка — напишите администратору.
    ```
  - Если авто найдено и присвоено пользователю:
    ```
    🚗 Номер: ХХХХХХ
    ✅ Теперь вы владелец этого авто! Статус обновлён, фото добавлено.
    ```
  - Если авто найдено и пользователь уже владелец:
    ```
    🚗 Номер: ХХХХХХ
    ✅ Статус авто обновлён, фото добавлено.
    ```
  - Если авто не найдено:
    ```
    🚗 Номер: ХХХХХХ
    ✅ Авто добавлено, вы указаны владельцем. Фото сохранено.
    ```

---

## 5️⃣ Важные детали
- Первый запрос к профилю — всегда с `auth: { user_id: 1, role: 'admin' }`
- Все остальные — с реальными user_id и role пользователя
- Если пользователь не найден — обязательно создать его перед дальнейшими действиями
- Фото всегда добавляется через отдельный эндпоинт `/api/photos/add.php`, **кроме случая создания авто** (там фото прикладывается сразу)
- Номер для отображения всегда в верхнем регистре, для запросов — как есть
