## 🎯 Цели и назначение бота

### Основная миссия
Telegram-бот CabrioRide является официальным мостом между Telegram-группой клуба и WebApp. Все функции доступны только участникам Telegram-группы клуба.

### Ключевые задачи
- ✅ Автоматизация приветствий новых участников
- ✅ Проверка членства и управление ролями
- ✅ Уведомления о важных событиях клуба
- ✅ Авторизация в WebApp через Telegram
- ✅ Поиск и распознавание автомобилей
- ✅ Интеграция с backend API

## 🚀 Основные функции (MVP)

### 1. Приветствие новых участников

#### 1.1. Автоматическое приветствие
**Триггер:** Новый пользователь добавлен в группу клуба

**Действия бота:**
- Приветствует участника с упоминанием через @username
- Отправляет краткую инструкцию по использованию бота и клуба
- Сохраняет в БД все доступные данные пользователя:
  - `telegram_id` — ID пользователя в Telegram
  - `username` — Username из Telegram  
  - `first_name` — Имя
  - `last_name` — Фамилия
  - `photo_url` — URL аватара (если есть)
  - `language_code` — Язык (если доступно)
  - `auth_date` — Дата авторизации/вступления
  - `join_date` — Дата вступления
  - `role: "guest"`

**Формат приветственного сообщения:**
```
👋 Привет, @username!
🎉 Добро пожаловать в клуб CabrioRide!

💬 Расскажи пару слов о себе и переходи в бот для регистрации:
👉 @CabrioControl_bot
```

#### 1.2. Уведомление о выходе участника
**Триггер:** Пользователь покинул группу клуба

**Действия бота:**
- Отправляет сообщение о выходе участника
- Упоминает пользователя через @username или имя

**Формат сообщения о выходе:**
```
😔 @username покинул клуб CabrioRide.

Будем скучать! Надеемся увидеться снова! 👋
```

#### 1.3. Обработка команды /start
**Триггер:** Пользователь отправляет команду `/start`

**Логика проверки:**
1. Проверяет членство в клубном чате
2. Если не состоит — отправляет заглушку с инструкцией вступить в чат
3. Если состоит — проверяет роль пользователя:
   - **Не завершил регистрацию** (роль "new" или "external") → приветствие + кнопка «Зарегистрироваться»
   - **Завершил регистрацию** → стандартное приветствие + кнопка «Перейти в приложение»

### 2. Управление членством и ролями

#### 2.1. Автоматическое создание записи
**Условие:** Пользователь впервые обращается к боту или добавляется в группу

**Действия:**
- Создаёт запись в таблице `users`
- Сохраняет все Telegram-данные
- Устанавливает начальную роль "guest"

#### 2.2. Обработка выхода из группы
**Триггер:** Пользователь покинул группу

**Действия:**
- Меняет роль пользователя на "external"
- Отправляет уведомление в группу о выходе участника
- Прекращает обработку команд от этого пользователя

#### 2.3. Обработка возвращения в группу
**Триггер:** Пользователь вернулся в группу

**Действия:**
- Если ранее завершал регистрацию → роль "registered"
- Если не завершал регистрацию → роль "guest"

### 3. Уведомления о событиях

#### 3.1. Типы уведомлений
- ✅ Регистрация нового участника в приложении
- ✅ Добавление автомобиля
- ✅ Создание событий
- ✅ Добавление гид-объектов
- ✅ Создание визиток
- ✅ Системные уведомления

#### 3.2. Настройка уведомлений
- Конфигурация через `config/config.php` (главный файл конфигурации в корне проекта)
- Использование функций `getBotConfig()` и `getNotificationText()` для доступа к настройкам
- Возможность включения/отключения каждого типа через `isNotificationEnabled()`
- Настройка шаблонов сообщений с подстановкой переменных

### 4. Авторизация в WebApp

#### 4.1. Deep-link интеграция
- Кнопка «Зарегистрироваться» → WebApp на страницу регистрации
- Кнопка «Перейти в приложение» → WebApp на главную страницу
- Передача данных Telegram в приложение

#### 4.2. Проверка доступа
- WebApp проверяет членство в чате
- При отсутствии членства — показ заглушки
- Передача `user_id`, `username` и других данных

### 5. Поиск и распознавание автомобилей

#### 5.1. Распознавание номера по фото (личные сообщения)
**Триггер:** Пользователь отправляет фото автомобиля в личные сообщения с ботом

**Процесс:**
1. Бот отправляет фото на `/api/ocr`
2. Получает распознанный номер и статус авто
3. Отвечает пользователю:
   - ✅ "Распознан номер: 0070MX7. Такой номер есть в клубе, статус авто: active."
   - ❌ "Распознан номер: 0070MX7. Такого номера нет в клубе."
   - ⚠️ "Не удалось распознать номер. Попробуйте другое фото."
4. **Предлагает оставить визитку** с кнопками "Да"/"Нет"

#### 5.2. Поиск по номеру (текстовый запрос)
**Триггер:** Пользователь отправляет номер текстом в личные сообщения

**Процесс:**
1. Бот отправляет запрос на `/api/plate-search`
2. Получает `found: true/false`
3. Отвечает пользователю:
   - ✅ "В клубе есть авто с таким номером."
   - ❌ "В клубе нет авто с таким номером."

#### 5.3. Распознавание номера в групповом чате
**Триггер:** В групповом чате отправляется фото с текстом "?"

**Процесс:**
1. Бот автоматически распознаёт номер на фото через `/api/ocr`
2. Проверяет наличие авто в базе через `/api/plate-search`
3. Отправляет ответ в групповой чат с результатом:
   - ✅ "Распознан номер: 0070MX7. Авто найдено в клубе, статус: active."
   - ❌ "Распознан номер: 0070MX7. Авто не найдено в клубе."
   - ⚠️ "Не удалось распознать номер на фото."

**Ограничения:**
- Функция работает только в групповом чате клуба
- Доступна только участникам группы
- Ответ виден всем участникам группы
- **НЕ предлагает оставить визитку** (только информационный ответ)
- **Единственное сообщение в группе, на которое реагирует бот**

**Формат ответа в групповом чате:**
```
Распознан номер
🚗 0070MX7
✅ Активный
```

или

```
Распознан номер
🚗 ABC123
🚫 Нет в клубе
```

**Формат ответа в личных сообщениях:**
```
Распознан номер
🚗 0070MX7
✅ Активный

💼 Оставляешь визитку?
[✅ Да] [❌ Нет]
```

## 🛡️ Безопасность и контроль доступа

### 1. Проверка членства
- **Обязательно** при каждом взаимодействии с ботом
- Проверка через Telegram API
- Блокировка функций для не-участников

### 2. Роли и права доступа
- **external** — только заглушка с предложением вступить в клуб
- **guest** — базовые функции (приветствие, переход в WebApp)
- **new** — регистрация через WebApp
- **registered** — полный доступ к функциям
- **member** — полный доступ к функциям
- **moderator/admin** — полный доступ к функциям
- Проверка прав через `canExecuteBotCommand()` из конфигурации

### 3. Лимиты и ограничения
- Настройка лимитов через `config/config.php` (главный файл конфигурации в корне проекта)
- Использование функции `getAppConfig()` для доступа к лимитам
- Ограничения на количество проверок авто
- Ограничения на создание визиток

## 🔧 Технические требования

### 1. Архитектура
- **Язык:** PHP 8.1 (PSR-12)
- **Архитектура:** Webhook (без постоянного процесса)
- **Интеграция:** Telegram Bot API
- **Взаимодействие с БД:** Только через backend API

### 2. Структура файлов
```
bot/
├── webhook.php (точка входа + логирование)
├── handlers/MessageHandler.php (обработка сообщений)
├── commands/ (команды бота)
│   ├── StartCommand.php
│   ├── HelpCommand.php
│   ├── TestCommand.php
│   ├── OcrCommand.php
│   └── PlateSearchCommand.php
└── services/ (сервисы)
    ├── BotService.php (отправка сообщений)
    ├── ApiService.php (работа с API)
    ├── UserService.php (работа с пользователями)
    └── NotificationService.php (уведомления)

config/ (в корне проекта)
├── config.php (главный файл конфигурации)
├── app.config.php (настройки приложения)
├── bot.config.php (настройки бота)
└── sectionGroups.php (роли и права доступа)
```

### 3. Логирование
- Все входящие запросы в `bot/webhook.log`
- Ключевые действия и события
- Аудит для отладки

## 🚫 Что бот НЕ обрабатывает в групповом чате

### Игнорируемые сообщения:
- ❌ Обычные текстовые сообщения
- ❌ Простые фото (без текста "?")
- ❌ Стикеры, GIF, видео
- ❌ Голосовые сообщения
- ❌ Документы и файлы
- ❌ Пересланные сообщения
- ❌ Ответы на сообщения

### Обрабатываемые события:
- ✅ Присоединение новых участников (приветственное сообщение)
- ✅ Выход участников (сообщение о выходе)
- ✅ Фото с "?" (распознавание номеров)
- ✅ Уведомления о событиях клуба

### Принцип работы:
Бот в групповом чате работает **только в фоновом режиме**:
- ✅ Отслеживает присоединение/выход участников
- ✅ Отправляет уведомления о событиях
- ✅ Обрабатывает фото с "?" (распознавание номеров)
- ❌ **НЕ реагирует на обычные сообщения**

Это позволяет избежать спама и сохранить естественное общение в группе.
