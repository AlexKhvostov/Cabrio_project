# Процесс деплоя CabrioRide

Актуально на 8 сентября 2026. Сборка `npm run build` для этого проекта **не нужна**: на сервер уезжают PHP, HTML, CSS и JS как есть.

Где локально, где тест, где бой — **[docs/ENVIRONMENTS.md](ENVIRONMENTS.md)**. Ниже только *как* копировать файлы.

## Куда выкладывать

На одном хостинге два сайта. Папки разные, перепутать нельзя.

| Среда | Папка на FTP | Когда |
|---|---|---|
| Тест | `www/dev.cabrioride.by/app` | проверка до показа клубу |
| Бой | `www/cabrioride.by/app` | только по команде «на бой» / «на прод» |

«Заливай» без уточнения — **спросить, куда**. На бой не копировать, пока владелец не сказал явно.

| | |

**Никогда не затирать на сервере:** `.env` той среды, куда копируете; папку загрузок (`uploads/`); логи; чужие сайты рядом (`club`, лендинг в корне домена). `.env` теста и `.env` боя — **разные файлы**, один другим не подменять.

Выкладка на бой — **только по прямой команде** владельца с указанием среды.

## Когда выкладывать

1. Правки сделаны локально.
2. Сначала тест (`www/dev.cabrioride.by/app`), если владелец не сказал иначе.
3. На бой — только после явной команды; файлы в `www/cabrioride.by/app`.
4. Проверка в Telegram: **тот бот, который относится к этой среде** → приложение → затронутые экраны.

Откат: предыдущие файлы можно взять из git или из бэкапа хостинга (`backups/` в аккаунте).

## Git

- Источник правды по коду: GitHub, когда владелец просит коммит.
- Секреты (`.env`, `.secrets/`) в репозиторий не кладём.
- SSH-ключи для будущего входа: `.secrets/ssh/` (тоже не в git).

## Проверка после выкладки

- Главная открывается из Telegram
- Участники / авто / профиль
- Карта: видна без GPS, ⏻ показывает меня, повторное нажатие скрывает
- Бот отвечает, webhook без ошибок

## SSH (когда поддержка включит)

Тогда можно будет заходить ключом и делать обновление через git на хостинге. Пока этого нет — FTP.
