# Статусы сущностей и роли пользователей CabrioRide

> **Важно:** У пользователей есть только **роли**, НЕ статусы! Статусы есть только у сущностей (автомобили, события, гид-объекты и т.д.).

---

## 👥 Роли пользователей (users)

У пользователей **ТОЛЬКО роли**, статусов нет!

| ID | Код        | Название         | Описание                                      |
| ---|------------|------------------|-----------------------------------------------|
| 1  | external   | Внешний          | Не член клуба, не состоит в чате              |
| 2  | guest      | Гость            | В чате, не начал регистрацию                  |
| 3  | user       | Пользователь     | Завершил базовую регистрацию, не подтверждён  |
| 4  | member     | Участник         | Подтверждён модератором, полный доступ        |
| 5  | moderator  | Модератор        | Может подтверждать участников, модерировать   |
| 6  | admin      | Администратор    | Полный доступ к управлению клубом             |

### 🔄 Переходы ролей пользователей:
- **external → guest** — вступил в чат
- **guest → user** — заполнил анкету, выбрал авто/гостя
- **user → member** — подтверждён модератором
- **member → moderator** — назначен администратором
- **Любая роль → external** — покинул чат

## 🚗 Статусы автомобилей (cars)

У автомобилей есть статусы для отслеживания их состояния в системе.

| ID | Код              | Название    | Описание                                      |
|----|------------------|-------------|-----------------------------------------------|
| 1  | `noticed`        | Замечен     | Автомобиль замечен ботом по фото, владелец не найден |
| 2  | `business_card`  | Визитка     | Авто добавлено по визитке, владелец не подтверждён |
| 3  | `deleted`        | Удалён      | Удалён из системы                             |
| 4  | `archived`       | В архиве    | В архиве (продан, не используется)            |
| 5  | `blocked`        | Заблокирован| Заблокирован (подозрительный номер, нарушение) |
| 6  | `pending`        | На модерации| Ожидает проверки модератором                  |
| 7  | `active`         | Активен     | Активный автомобиль участника                 |

### 🔄 Переходы статусов автомобилей:
- **noticed → active** — установлен владелец
- **business_card → active** — подтверждён владелец
- **active → archived** — продан/не используется
- **Любой → deleted** — удалён из системы
- **Любой → blocked** — заблокирован модератором

## 📋 Статусы других сущностей

### 🗺️ События (events) — планируется
- `draft` — черновик
- `published` — опубликовано
- `cancelled` — отменено
- `completed` — завершено
- `archived` — в архиве

### 🏛️ Гид-объекты (guide_objects) — планируется
- `pending` — на модерации
- `approved` — одобрено
- `rejected` — отклонено
- `archived` — в архиве

### 📝 Отзывы (reviews) — планируется
- `pending` — на модерации
- `approved` — одобрен
- `rejected` — отклонён
- `hidden` — скрыт

## 🎯 Использование в коде

### Проверка роли пользователя:
```php
// Проверка, что пользователь — участник или выше
if (in_array($user['role'], ['member', 'moderator', 'admin'])) {
    // Доступ к основному функционалу
}
```

### Проверка статуса автомобиля:
```php
// Проверка, что автомобиль активен
if ($car['status'] === 'active') {
    // Автомобиль в активном использовании
}
```

### Получение статуса по ID:
```php
// Получить статус автомобиля по ID
$status = Status::findById($car['status_id']);
```

---

## ⚠️ Важные правила

1. **Пользователи НЕ имеют статусов** — только роли
2. **Сущности имеют статусы** — для отслеживания состояния
3. **Роли определяют доступ** — что может делать пользователь
4. **Статусы определяют состояние** — в каком состоянии находится сущность
5. **Автоматические переходы** — только для статусов сущностей, не для ролей пользователей
