# Использование раздела "Карта"

## 1. Название сценария
Использование раздела "Карта"

## 2. Цель сценария
Дать участникам клуба возможность видеть друг друга на карте: кто сейчас делится геолокацией — тот виден остальным. Это экран «где свои», а не отдельный продукт с голосом и метками.

## 3. Участники и роли
- Пользователь
- Backend

## 4. Предусловия
- Пользователь авторизован через Telegram WebApp.
- Смотреть чужие точки: роль member и выше.
- Делиться своей точкой / скрыть себя: роль user и выше.

## 5. Основной поток (пошагово)
1. Пользователь открывает «Карта». Карта сразу видна, центр по умолчанию — Минск.
2. Если есть живые точки других людей — они на карте и в списке «Сейчас на карте».
3. Пока пользователь не включил геолокацию, его самого не видно. На экране короткая подсказка: включи кнопку ⏻, чтобы свои видели тебя. Карта при этом не гаснет и не прячется.
4. Пользователь нажимает ⏻. Браузер / Telegram спрашивает разрешение на геолокацию.
5. Если разрешил — его точка уходит на сервер, он появляется у остальных. Кнопка ⏻ горит. Можно включить «держать меня в центре».
6. Нажатие на метку или строку в списке открывает **карточку участника** (свою метку — тоже свою карточку). Карта подъезжает к человеку.
7. Пользователь снова нажимает ⏻ — передача координат останавливается, его точка сразу удаляется с сервера, у остальных он пропадает. Карта остаётся, можно смотреть других.

## 6. Альтернативные потоки / Edge-cases
- Нет разрешения на геолокацию — карта доступна для просмотра, сверху понятная ошибка, себя не видно.
- Нет геолокации в устройстве — то же: смотреть можно, делиться нельзя.
- Точка старше `map_live_time_min` минут (по умолчанию 60) не показывается.
- Роль ниже member — чужие точки не загружаются, список объясняет, что это для участников клуба.
- Роль ниже user — нельзя отправить свою точку.

## 7. Свежесть точки (не роль участника)
- Точка, обновлённая меньше 3 минут назад, слегка пульсирует — человек недавно был здесь.
- Роль участника на карте не показывается. У участников клуба есть только роли, не статусы.

## 8. UX-детали
- Карта всегда можно смотреть, даже с выключенным GPS.
- Нет затухания всей карты и нет принудительного скрытия через 20 секунд.
- Подсказка про ⏻ видна только пока пользователь себя не показывает.
- Голос и метки «пробка / ГАИ» в этом сценарии не используются.

## 9. Интеграции и API
- `GET /api/user-locations` — кто сейчас на карте (member+)
- `POST /api/user-locations` — отправить свои координаты (user+)
- `DELETE /api/user-locations` — сразу скрыть себя (user+)

## 10. Уведомления
- Подсказка: как начать показывать себя.
- Ошибка, если геолокация запрещена или не сработала.
- Короткое подтверждение: «Тебя больше не видно на карте».

## 11. Ограничения и лимиты
- Живая точка: `map_live_time_min` в `.env`.
- Частота отправки своих координат: `map_upd_sec` / `map_upd_moving_sec`.
- Обновление чужих точек: `map_users_refresh_idle_sec` / `map_users_refresh_moving_sec`.
- Координаты не копятся: при выключении строка удаляется; устаревшие не отдаются в списке.

## 13. Тест-кейсы (минимум)
- Открыл карту без GPS — видна карта Минска и чужие живые точки (если есть), себя нет.
- Включил ⏻, разрешил геолокацию — появилась своя метка, у другого участника ты тоже появился.
- Нажал на человека в списке или на метку — открылась карточка участника.
- Выключил ⏻ — своя метка пропала сразу, карта осталась.
- Запретил геолокацию — карта не исчезла, показана ошибка.
