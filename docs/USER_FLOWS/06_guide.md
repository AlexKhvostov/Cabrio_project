# Отзывы: карточки клуба и оценки

В меню пункт называется **«Отзывы»**. Файл страницы — `frontend/pages/services.php`. В API и БД сущность по-прежнему `guide_objects` (не переименовывали, чтобы не ломать данные).

## 1. Название сценария
Карточки для отзывов клуба (мойки, масла, сервисы, кафе) и оценки к ним.

## 2. Цель сценария
Держать в одном месте проверенные точки клуба и честные оценки участников.

## 3. Участники и роли
- Участник с ролью **member** и выше: смотрит список, открывает карточку, пишет отзыв
- Кто может создавать и править карточки — см. `config/sectionGroups.php`
- Админ/модератор: может убрать карточку (статус сущности, не роль человека)

## 4. Предусловия
- Пользователь открыл Mini App из Telegram и авторизован
- Есть доступ к разделу (обычно member+)

## 5. Основной поток (как сделано сейчас)
1. Нижнее меню → **Отзывы**.
2. Список плиток: фото, название, ярлыки, средняя оценка если отзывы уже есть. Поиск понимает `#мойка` и тап по чипу.
3. Кнопка **+** в шапке — новая карточка: фото, название, описание, ярлыки. Тип и вид **не спрашиваем**.
4. Тап по плитке — большая карточка: обложка, описание, ярлыки, блок оценок, список отзывов.
5. **Написать отзыв** — модалка поверх (не вместо карточки): текст + три оценки 1–5 звёздами (качество, скорость, цена). Один человек — один отзыв на карточку.
6. Тап по отзыву — просмотр. **Свой** отзыв: кнопки Изменить и Удалить. Чужой — только чтение.
7. **Изменить** на существующей карточке места: та же сетка, что в просмотре; светлеют поля. Название правится на обложке. Карточка не разъезжается.

## 7. Роли и статусы
У людей только **роли**. У карточки и отзыва — статус сущности, при создании обычно `active`.

## 8. API (рабочие пути)
Запросы идут на `backend/routes/api.php?route=...`:

- `GET/POST /api/guide-objects`, `GET/PATCH/DELETE /api/guide-objects/{id}`
- поле `labels` при создании и правке карточки
- `GET /api/ref/labels` — подсказки ярлыков
- `GET/POST /api/reviews`

Справочники типов/видов (`/api/ref/guide-object-types`, `kinds`) ещё есть, форма ими не пользуется.
